# API reference

> Generated by `npm run docs` from the route definitions. Edit `scripts/gen-api-docs.ts`, not this file.

Base URL: `http://localhost:5000` — 103 endpoints across 14 groups.

## Conventions

Every response uses the same envelope:

```json
{ "success": true, "data": { }, "message": "Human readable", "errors": [] }
```

Failures keep the shape and add a machine-readable `code`:

```json
{
  "success": false,
  "message": "Goal not found",
  "code": "NOT_FOUND",
  "errors": []
}
```

| Code | HTTP | Meaning |
| --- | --- | --- |
| `VALIDATION_ERROR` | 400 | The request body or query failed validation; see `errors` |
| `BAD_REQUEST` | 400 | The request was well formed but not allowed |
| `UNAUTHORIZED` | 401 | Missing, malformed or expired access token |
| `FORBIDDEN` | 403 | Authenticated, but not allowed to touch this resource |
| `NOT_FOUND` | 404 | No such document, or it belongs to another user |
| `CONFLICT` | 409 | Duplicate or conflicting state |
| `TOO_MANY_REQUESTS` | 429 | Rate limited; `errors[0].retryAfterSeconds` says when to retry |
| `INTERNAL_ERROR` | 500 | Unexpected failure; details are logged, not returned |

### Authentication

Send the access token as a bearer credential:

```http
Authorization: Bearer <accessToken>
```

Only `/api/auth/register`, `/api/auth/login`, `/api/auth/refresh`, `/api/auth/logout` and `POST /api/auth/logout` may be called without a token. Everything else returns `401`.

Access tokens are short lived. Refresh with `POST /api/auth/refresh`; the response carries a new pair and the old refresh token is invalidated. Replaying an already-rotated token revokes the whole token family, which signs the user out everywhere.

### Rate limits

A global limiter applies to everything under `/api`, and credential endpoints have a tighter per-IP limit (20 requests per 15 minutes). `429` responses include `errors[0].retryAfterSeconds`.

### Pagination

List endpoints accept `page` (1-based) and `limit` (default 20, maximum 100) and return:

```json
{ "items": [], "meta": { "page": 1, "limit": 20, "total": 89, "totalPages": 5 } }
```

Malformed paging values fall back to the defaults rather than erroring. CSV list parameters (`diet`, `equipment`, `muscleGroup`, `excludeAllergens`) accept `a,b,c`.

### Dates

Day-level parameters (`day`, `targetDate`, `startDate`, `endDate`) are calendar dates in `YYYY-MM-DD` and are interpreted in UTC, so a day boundary is identical on the server and on the device.
